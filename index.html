// Research Background & Goal

TECHNICAL CHALLENGES

GPS-denied navigation in collapsed structures and disaster zones demands compact perception, stable long-range RL training, and real-time target detection — all validated in parallel GPU simulation.

Perception · Convolutional Autoencoder

Raw depth images are high-dimensional and slow for RL. A Convolutional Autoencoder compresses each depth frame into a compact 32-dimensional latent vector, accelerating policy training while preserving spatial structure for navigation.

Sparse Reward · Curriculum Learning

Long-distance navigation under sparse rewards fails without staged training. Distance-based curriculum learning with 5 difficulty levels up to 33 meters progressively teaches the agent to reach distant targets in complex enclosed layouts.

Real-Time Vision · YOLO v11

Beyond navigation, the system localizes survivors and targets visually. YOLO v11 provides real-time object detection fused with the RL navigation stack for autonomous target identification in low-visibility disaster scenarios.

Simulation Engine · Isaac Sim & Isaac Lab

The full pipeline is built on NVIDIA Isaac Sim & Isaac Lab, enabling massive parallel GPU physics simulation — thousands of environment rollouts for stable PPO training in photorealistic, physics-accurate disaster environments.
